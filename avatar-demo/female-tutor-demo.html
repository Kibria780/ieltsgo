এটাই IELTSGo-র আসল পথ: AI-এর TTS অডিও ফাইল দিলে তার আওয়াজের জোর (amplitude) মেপে মুখ খুলবে-বন্ধ হবে। একটি MP3/WAV ফাইল বেছে নিন।

⚙️ আরও / More

Web-native demo: original SVG character + JavaScript lip-sync engine. No Adobe Illustrator / Character Animator / After Effects files exist — this machine has no Adobe tools, so the avatar was built to run directly in a browser instead. See INTEGRATION.md for how it connects to IELTSGo.
