# IELTSgo 🎙️

AI ভার্চুয়াল ইংরেজি স্পিকিং অ্যাসিস্ট্যান্ট — কোনো সাইন-আপ ছাড়াই।

## কী কী আছে
- 🎙️ মাইক বা টাইপে ইংরেজিতে কথা বলা — AI মুখে (ভয়েসে) উত্তর দেয়
- 📝 ভুল ইংরেজি বললে পয়েন্ট আকারে ভুল + বাংলায় সহজ ব্যাখ্যা
- 🎯 মক টেস্ট মোড — IELTS Speaking Part 1, 2, 3 (টাইমারসহ), শেষে AI-ভিত্তিক ব্যান্ড স্কোর
- 🆓 সম্পূর্ণ ফ্রি, কোনো অ্যাকাউন্ট/ফোন নাম্বার লাগে না (keyless AI)

## চালানো
শুধু `index.html` ফাইলটা যেকোনো ব্রাউজারে (Chrome ভালো) খুললেই চলবে।

## Vercel-এ ডেপ্লয়
1. [vercel.com](https://vercel.com)-এ যাও → **Add New → Project**
2. **Import Git Repository** → এই রিপো (`ieltsgo`) সিলেক্ট করো
3. **Deploy** চাপ দাও — ব্যাস, পাবলিক লিংক রেডি!

*Static single-file site — কোনো build step বা environment variable লাগে না।*
